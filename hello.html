Os comandos principais para ligar a um repositório GitHub:

  1. git clone "link do repositório": copiar o repositório do GitHub para o computador
  2. touch nomedoficheiro.html: criar um ficheiro novo
  3. git add nomedoficheiro: preparar o ficheiro para o commit
  4. git commit -m "observação do que se fez": guardar as alterações
  5. git status: permite ver onde nos situamos no repositório
  6. git push: publicar as alterações do computador para o GitHub
  7. git commit -am "observação da alteração que se fez": fazer commit de todas as alterações
  8. git pull: copiar as mudanças feitas no GitHub para o computador

Resolver conflitos: Merge Conflicts

Estes conflitos aparecem quando duas pessoas fazem mudanças ao mesmo tempo no mesmo ficheiro e na mesma linha.

Outros comandos de Git

  • git log: verificar todas as mudanças no código de um repositório
  • git reset --hard <nº do commit>: anular as mudanças feitas a partir desse commit
  • git reset --hard origin/master: recuperar a versão original do GitHub

Branching

Permite criar uma ramificação no repositório, para trabalhar em diferentes partes do projeto ao mesmo tempo.

  1. git branch: verificar em que branch estamos
  2. git checkout -b nomedabranch: criar uma nova branch
  3. git checkout nomedabranch (ou master): mudar entre branches
  4. git merge nomedabranch: juntar as alterações de uma branch à master

Ferramentas que nos ajudam no GitHub em grandes projetos

  1. Fork: permite que outros contribuam para o seu código
  2. Pull requests: ver e rever quem pede para contribuir
  3. GitHub Pages: criar páginas de internet de forma rápida
